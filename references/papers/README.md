# Primary paper archive

This directory contains local copies of primary papers and numerical supplements used by the MCX project. Publisher files are excluded from Git; this tracked inventory preserves identity and checksums. The original four simulation papers were read in full and visually checked page-by-page on August 13, 2026. The Priority 1 optical-property sources acquired later that day passed identity, archive-integrity, and page-render checks; their scientific transcription is tracked separately in the optical-property ledger and audit.
